# Зерно — сайт кофейни с 3D-чашкой и заказом навынос

Демо-проект для портфолио: кофейня вымышленная, сайт рабочий.

**Открыть:** https://davnat0111-gif.github.io/zerno-coffee/

## Что умеет
- **3D-сцена на Three.js:** керамическая чашка с латте-артом, пар на собственном шейдере (шум), кофейные зёрна, которые разлетаются при прокрутке, мягкие тени
- **Меню с вкладками:** размер S/M/L и выбор молока сразу меняют цену
- **Корзина:** количество, промокод `ПЕРВЫЙ` (−10%), время самовывоза (ближайшие слоты по реальному времени, ночью — на завтра), номер заказа
- Корзина сохраняется после перезагрузки страницы (localStorage)
- Адаптив под телефон

HTML, CSS, JavaScript без фреймворков. Сделано с помощью Claude Code.
